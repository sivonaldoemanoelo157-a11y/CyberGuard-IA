# CyberGuard IA 🛡️

Central inteligente de proteção digital.

## Objetivo
Desenvolver uma inteligência artificial para ajudar a identificar ameaças digitais, golpes e acessos suspeitos.

## Proteções planejadas
- Google e Gmail
- WhatsApp
- Instagram
- Facebook
- Contas de jogos

## Missão
Ajudar pessoas e empresas a proteger suas contas e dados digitais.
